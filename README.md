# RAG Session VCET

A hands-on, local Retrieval-Augmented Generation (RAG) workshop for third-year CSE students.

The project builds a campus handbook assistant from scratch using:

- Keyword search with TF-IDF and cosine similarity
- Optional semantic embeddings through Ollama
- Local answer generation with Ollama
- A simple browser interface and Python HTTP server
- Build-along exercises, evaluation tools, and tests

## Quick start

```bash
cd RAG-Session-VCET--main
python3 -m venv .venv
.venv/bin/python app.py
```

Open <http://127.0.0.1:8000> and choose **Build sample index**.

For Windows, see the [project README](RAG-Session-VCET--main/README.md) for PowerShell commands and the complete workshop instructions.
